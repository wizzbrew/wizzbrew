# Wizzbrew

A Discord bot for SpeedGaming Live 2026. Ask it about the schedule, streams, standings and
players. It answers from [Wizzrobe](https://onsite.speedgaming.org), the event's onsite tool.
Link your Wizzrobe account and it can also sign you up as crew or acknowledge your match.

Built on Vercel with a Claude Haiku router and Claude Sonnet responders.

Status: planning. See [plan.md](plan.md), and [docs/wizzrobe-surface.md](docs/wizzrobe-surface.md)
for what Wizzrobe exposes.
