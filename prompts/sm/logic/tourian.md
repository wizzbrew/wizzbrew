# Tourian (`tourian`): logic rules

## Entry rule

Tourian is not modeled in the logic: it has no item locations and no entry rule, so there are no per-location rules for it. The randomizer ROM patch opens the path to it once Kraid, Phantoon, Draygon and Ridley are dead. No boss kill is modeled in either logic, and Mother Brain is the goal, not part of the logic.
