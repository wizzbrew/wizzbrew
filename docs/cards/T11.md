GOAL
Implement Wizzrobe OAuth (authorization code with PKCE S256, refresh, revoke) for `/link`, and
the one-time login script for the bot's own read-only account.

CONTEXT
Users link their Discord account to their Wizzrobe account so the bot can act as them. The
callback handler (wave 3) calls `finishLink`; `tokens.ts` (in parallel) calls `refresh`;
`/unlink` calls `revoke`. Tokens never appear in logs, URLs shown to users, or errors.

EXTERNAL FACTS (checked live 2026-10-15)
- Metadata: GET `<WIZZROBE_BASE_URL>/.well-known/oauth-authorization-server` returns
  `{"issuer":"https://wizzrobe.synack.live/","authorization_endpoint":"https://wizzrobe.synack.live/authorize","token_endpoint":"https://wizzrobe.synack.live/token","registration_endpoint":"https://wizzrobe.synack.live/register","revocation_endpoint":"https://wizzrobe.synack.live/revoke","scopes_supported":["wizzrobe:read","wizzrobe:write"],"code_challenge_methods_supported":["S256"],"token_endpoint_auth_methods_supported":["client_secret_post","client_secret_basic"]}`.
  The base URL host may differ from the endpoints' host: always use the endpoints from the
  metadata. Fetch it once per process and cache it in memory.
- The MCP resource is `config().wizzrobeMcpUrl` (https://wizzrobe.synack.live/mcp).
- Token responses: `{access_token, refresh_token?, expires_in, token_type, scope}`. Errors:
  JSON `{error, error_description?}`.
- whoami (through `callTool(token, "whoami", {})`) returns
  `{"user_id":206,"username":"...","display_name":null,"can_write":true,"tenants":[{"slug":"sgl26","name":"SpeedGaming Live 2026","roles":[],"features":[...]}]}`.

BEHAVIOR
1. Helpers (exported for the script): `pkcePair(): {verifier, challenge}` (verifier =
   base64url of 32 random bytes; challenge = base64url(SHA-256(verifier)), no padding),
   `discoverMetadata()`, `exchangeCode(code, verifier, redirectUri)`.
2. startLink: state = base64url(16 random bytes); `kv().set(keys.oauthState(state),
   {verifier, discordUserId}, 600)`; return the authorize URL with `response_type=code`,
   `client_id`, `redirect_uri=config().wizzrobeOauthRedirectUri`, `scope=wizzrobe:read
   wizzrobe:write`, `state`, `code_challenge`, `code_challenge_method=S256`,
   `resource=config().wizzrobeMcpUrl`.
3. finishLink: read the state record; missing or expired -> `UserInputError("That link request
   expired. Run /link again.")`. Delete it before exchanging (single use). POST the token
   endpoint, form-urlencoded: grant_type=authorization_code, code, redirect_uri, client_id,
   client_secret (client_secret_post), code_verifier, resource. Then whoami with the access
   token; find the tenant whose slug is `config().wizzrobeTenant`; none ->
   `UserInputError("Your Wizzrobe account isn't in this event's community yet. Join it on
   Wizzrobe, then run /link again.")`. Save with `saveLink(discordUserId, {sealedRefreshToken:
   await seal(refresh_token), wizzrobeUserId: user_id, username, roles: tenant.roles, canWrite:
   can_write, linkedAt: Date.now(), rolesCheckedAt: Date.now()})`. A token response without a
   refresh_token -> `WizzrobeError(502, "Wizzrobe sent no refresh token")`.
4. refresh: grant_type=refresh_token, refresh_token, client_id, client_secret, resource.
   Returns the new refresh token, or the old one when none comes back.
5. revoke: POST the revocation endpoint: token, token_type_hint=refresh_token, client_id,
   client_secret. 200 resolves.
6. Any non-2xx from metadata, token or revoke -> `WizzrobeError(status, error_description ??
   error ?? "oauth request failed", Retry-After seconds if present)`. Never put a token, code
   or secret in an error or log.
7. scripts/wizzrobe-login.ts: `configFor("wizzrobeBaseUrl", "wizzrobeMcpUrl",
   "wizzrobeOauthClientId", "wizzrobeOauthClientSecret")`; scope `wizzrobe:read` only;
   redirect `http://127.0.0.1:8976/callback` via `node:http` on 127.0.0.1 only; print the
   authorize URL, wait for the callback, check state, exchange, print the refresh token once
   with a line saying it goes into WIZZROBE_BOT_REFRESH_TOKEN, close the server. Exit 1 on any
   failure with the message.
