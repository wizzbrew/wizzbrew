BEHAVIOR (presser = `i.member?.user ?? i.user`; token `i.token`; payloads carry
`allowed_mentions: {parse: []}`)
1. Decode custom_id; null -> followup ephemeral "That button isn't mine." and stop.
2. confirm: `takePending(id, presser, now)`: "not_yours" -> followup flags 64 "Only the person
   who asked can confirm this." (message untouched); "expired" -> edit `{content: "That request
   expired. Ask again.", components: []}`; a PendingAction -> edit `{content: "Working on it...",
   components: []}`, `line = await executeAction(p)`, edit `{content: line, components: []}`.
3. cancel: the same take; not_yours and expired as above; otherwise edit `{content:
   "Cancelled.", components: []}`.
4. choose: `loadThread(threadId, presser, now)` (owner, or anyone on a public thread):
   not_yours -> followup flags 64 "That one is private."; expired -> the expired edit; otherwise
   `runAskPipeline({requestId, asker: await loadAsker(i), question: thread.question + "\n(Picked:
   " + value + ")", reply: {kind: "interaction", token, ephemeral: thread.ephemeral}, history:
   thread.turns, threadId: thread.id, forced: thread.decision, now})`.
5. private: `loadThread(threadId, presser, now)`: not_yours -> edit "That one is just for the
   person who asked."; expired or no `held` -> edit "Nothing is waiting here anymore. Ask again.";
   otherwise `p = renderAnswer(held.answer, {pendingId: held.pendingId, threadId})`, edit with
   p[0], followups flags 64 for the rest.
6. Any error: edit `{content: userMessageFor(err), components: []}`; if that fails too, log
   error; never rethrow.
