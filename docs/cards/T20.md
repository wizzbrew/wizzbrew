CONTRACT (do not change)

```ts
export function runComponent(i: APIMessageComponentInteraction, requestId: string, now: Date): Promise<void>;   // never throws
```

BEHAVIOR (presser = `i.member?.user ?? i.user`; token `i.token`; every payload carries
`allowed_mentions: {parse: []}`)
1. `decodeCustomId(i.data.custom_id)`; null -> followup ephemeral (flags 64) "That button
   isn't mine." and stop.
2. confirm: `takePending(id, presser, now)`:
   - "not_yours" -> followup ephemeral "Only the person who asked can confirm this." (the
     message and its buttons stay);
   - "expired" -> edit original `{content: "That request expired. Ask again.", components: []}`;
   - a PendingAction -> edit original `{content: "Working on it...", components: []}`, then
     `line = await executeAction(p)`, then edit `{content: line, components: []}`.
3. cancel: `takePending` the same way; not_yours -> the same ephemeral followup; expired ->
   the expired edit; otherwise edit `{content: "Cancelled.", components: []}`.
4. choose: `loadThread(threadId, presser, now)`: not_yours -> ephemeral followup "Only the
   person who asked can pick."; expired -> the expired edit; otherwise `runAskPipeline({requestId,
   interaction: i, question: thread.question + "\n(The asker picked: " + value + ")",
   ephemeral: thread.ephemeral, forced: thread.decision, now})`.
5. Any error: edit original `{content: userMessageFor(err), components: []}`; if that fails,
   log error; never rethrow.
