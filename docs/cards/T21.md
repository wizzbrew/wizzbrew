EXTERNAL FACTS
- `import { waitUntil } from "@vercel/functions"`: `waitUntil(promise)` keeps the function
  alive until the promise settles.
- Discord sends headers `X-Signature-Ed25519` and `X-Signature-Timestamp`; the signed message
  is `timestamp + rawBody`.

BEHAVIOR
1. interactions POST: `raw = await request.text()`; read both headers (missing -> 401);
   `verifyDiscordRequest(raw, sig, ts, config().discordPublicKey)`; false -> `new
   Response("invalid request signature", {status: 401})`. Only then `JSON.parse(raw)` (bad JSON
   -> 400). Type 1 -> `Response.json({type: 1})`. Otherwise `return handleInteraction(i,
   waitUntil)`. A config error -> 500 with no detail in the body (log the problems).
2. health GET: `Response.json({ok: true, configValid: checkConfig().valid, routes:
   Object.keys(ROUTES)})` with `Cache-Control: no-store`. Never output env names, values or
   problems.
