SCENARIOS (tests/e2e/slash.test.ts; assert on FakeDiscordApi calls and FakeWizzrobe calls)
1. `/ask what's on today` -> router picks schedule -> responder answers with a thinking block
   first -> one editOriginal with the text and an "Ask a follow-up" button; public deferral.
2. `/live` -> direct answer, FakeAnthropic receives no request.
3. `/ask sign me up to commentate match 1` as a linked user -> propose_action -> private answer
   behind the public deferral ("I sent you the answer privately" then an ephemeral followup with
   Confirm, Cancel, Change something) -> Confirm by the same user -> FakeWizzrobe saw
   signup_as_crew with "user-token" and `{match_id: 1, role: "commentator", tenant: "sgl26"}` ->
   the message edited with the result line.
4. Confirm pressed twice quickly -> the write runs once (second press: expired).
5. Confirm by another user -> ephemeral "Only the person who asked..." and no write.
6. Confirm after 11 minutes (FakeKv clock) -> expired.
7. The same ask while unlinked -> "Ask me to link your Wizzrobe account first (or use /link)."
8. `/link` -> ephemeral deferral -> the answer contains a markdown link to the authorize URL; the
   OAuth state is in FakeKv. "connect me to SGL" through /ask -> router picks account/link -> the
   same link answer, delivered privately.
9. Follow-up: the button from scenario 1 -> type 9 modal; the modal submit "and tomorrow?" -> the
   router request contains the earlier turns; the responder request's user message contains them.
10. A Wizzrobe 429 mid-answer (FakeWizzrobe.failTool on the connector path is out of reach: use
    a client tool path, matches_for_me, with get_match failing 429) -> "Wizzrobe is busy..."
11. A feature-off tool -> "That feature is not turned on for this event."
12. `/standings` without CHALLONGE_API_KEY -> the bracket and rules links, no table.
13. Over the daily budget -> the budget message; `/live` still answers.
14. A 4500-character answer -> one edit plus two followups.
15. An em dash in model output -> no dash reaches Discord.
16. An injection string in the question doesn't change the route's auth (L8): a public route
    stays on the bot token.
17. Kill switch set -> "Wizzbrew is paused right now."
18. A second /ask while the first is running (hold the first fake response) -> "Still working on
    your last one..."
