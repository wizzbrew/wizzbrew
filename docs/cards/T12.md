GOAL
Implement fresh Wizzrobe access tokens for the bot and for linked users, and the single module
that maps a Discord user to their Wizzrobe link (L19).

CONTEXT
Public answers use the bot's own read-only account; linked answers and every write use the
asking user's own token. Identity drifted across code paths in the last bot (L19), so this is
the only reader of link keys. "Me" resolves in code from the asker (L7).

BEHAVIOR: identity.ts
1. getLink/saveLink/deleteLink: `kv()` at `keys.link(id)`, no TTL. deleteLink also deletes
   `keys.userToken(id)`. No other module touches `keys.link` (a CI rule checks this).
2. loadAsker(i): user = `i.member?.user ?? i.user` (neither -> throw Error("interaction has no
   user")). discordName = `i.member?.nick ?? user.global_name ?? user.username`. guildId =
   `i.guild_id ?? null`. channelId = `i.channel?.id ?? i.channel_id ?? ""`. linked = null
   without a link record. With one, when `Date.now() - rolesCheckedAt > 600000`: refresh roles
   with `callTool(await userAccessToken(id), "whoami", {})`, take the tenant whose slug is
   `config().wizzrobeTenant` (roles, and can_write from the top level), save the record with a
   new rolesCheckedAt. If that throws NotLinkedError, linked = null (the link is gone). Any
   other error: log warn "identity.roles_refresh_failed" and keep the stored roles. linked =
   `{wizzrobeUserId, wizzrobeUsername: username, roles, canWrite}`.
   Discord types are `import type` from "discord-api-types/v10".

BEHAVIOR: tokens.ts
3. botAccessToken: `kv().get(keys.botToken())` holds `{accessToken, expiresAt,
   sealedRefreshToken?}`. If `expiresAt - 60000 > Date.now()`, return accessToken. Otherwise
   refresh with the stored refresh token (`open(sealedRefreshToken)`) or, when there is none,
   `config().wizzrobeBotRefreshToken`; store `{accessToken, expiresAt: Date.now() + expiresIn *
   1000, sealedRefreshToken: await seal(newRefreshToken)}` with no TTL (Wizzrobe may rotate the
   refresh token, so the newest one must survive); return. Errors propagate (log error
   "tokens.bot_refresh_failed" with the status only).
4. userAccessToken(id): `kv().get(keys.userToken(id))` holds `{accessToken, expiresAt}`; fresh
   -> return. Otherwise `getLink(id)`; none -> `NotLinkedError("Run /link first to connect your
   Wizzrobe account.")`. `refresh(await open(rec.sealedRefreshToken))`:
   - WizzrobeError 400 or 401 -> `deleteLink(id)`, then `NotLinkedError("Your Wizzrobe link
     expired. Run /link to connect again.")`;
   - other errors propagate;
   - success: if the refresh token changed, `saveLink(id, {...rec, sealedRefreshToken: await
     seal(new)})`; cache `{accessToken, expiresAt}` at keys.userToken(id) with TTL `max(expiresIn
     - 60, 1)`; return.
5. Never log a token or refresh token.
