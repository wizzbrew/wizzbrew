GOAL
Turn a verified Discord interaction into a deferred reply plus background work, and run the

CONTEXT
Discord needs an answer within 3 seconds, so every command is deferred and the work runs in
`waitUntil`. Visibility is fixed at deferral, before routing. Every failure must end in an
honest reply through `userMessageFor`, never a silent hang (L16, L17). Permission checks are
code, after routing (CLAUDE.md).

CONTRACT (do not change)
```ts
export interface PipelineRequest { requestId: string; interaction: APIInteraction; question: string; ephemeral: boolean; forced?: RoutingDecision; now: Date }
export function runAskPipeline(req: PipelineRequest): Promise<void>;   // never throws; always ends in editOriginal (L16)
export function shortcutRequest(i: APIChatInputApplicationCommandInteraction, now: Date): { question: string; decision: RoutingDecision } | null;
export function handleInteraction(i: APIInteraction, waitUntil: (p: Promise<unknown>) => void): Promise<Response>;
// link.ts (parallel): runLinkCommand(name: "link" | "unlink" | "me", i, requestId, now): Promise<void>
// component.ts (parallel): runComponent(i: APIMessageComponentInteraction, requestId, now): Promise<void>
```
Discord types are `import type` from "discord-api-types/v10"; numeric literals at runtime
(interaction types 1 PING, 2 APPLICATION_COMMAND, 3 MESSAGE_COMPONENT; option values sit in
`i.data.options[]` as `{name, type, value}`).

BEHAVIOR: dispatch.ts
1. requestId = `crypto.randomUUID()`, now = `new Date()`.
2. type 1 -> `Response.json({type: 1})`.
3. type 2: command name from `i.data.name`.
   - "ask": question from option "question"; ephemeral false.
   - "schedule", "live", "standings", "player": ephemeral false.
   - "link", "unlink", "me": ephemeral true; `waitUntil(runLinkCommand(name, i, requestId,
     now))`.
   - others -> `Response.json({type: 4, data: {content: "I don't know that command.", flags:
     64, allowed_mentions: {parse: []}}})`.
   For ask and shortcuts: `waitUntil(runAskPipeline({...}))`, where a shortcut is built inside
   the waited promise (shortcutRequest may throw UserInputError; it must still end in an
   edited reply, so wrap: on error edit with renderError(userMessageFor(err))).
   Reply at once `Response.json({type: 5, data: {flags: ephemeral ? 64 : 0}})`.
4. type 3 -> `waitUntil(runComponent(i, requestId, now))`; reply `Response.json({type: 6})`.
5. Anything else -> 400. handleInteraction itself never throws.

BEHAVIOR: shortcuts.ts
6. Option values as strings. `day` -> `parseUserDate(day, now)` (UserInputError propagates);
   decisions have confidence 1 and reason "shortcut /<name>":
   - schedule -> route schedule, params {day, stage, tournament} (absent ones omitted);
     question "Show the schedule" plus " for <day text>", " on stage <stage>", " in <tournament>"
     as given;
   - live -> route streams, question "What is live on each stage now, and what is next";
   - standings -> route standings, params {tournament}, question "Standings for <tournament>";
   - player -> route players, params {player: name}, question "Matches and results for <name>";
   - any other command -> null.

BEHAVIOR: ask.ts runAskPipeline(req)
7. In order, inside one try:
   1. `asker = await loadAsker(req.interaction)`;
   2. `await assertUnderBudget(req.now)`;
   3. `question = normalizeInput(req.question, i.data?.resolved)`;
   4. `decision = req.forced ?? await routeQuestion({requestId, asker, question, now,
      ephemeral})`;
   5. auth gate (code, never the prompt): `ROUTES[route].auth` "linked" and no
      `asker.linked` -> `NotLinkedError("")`; "staff" and the linked roles don't include
      "staff" or "admin" -> `UserInputError("That's for event staff.")`;
   6. `answer = await runResponder(route, decision, {requestId, asker, question, now,
      ephemeral})`;
   7. `answer.proposedAction` -> `p = await createPending(answer.proposedAction,
      asker.discordUserId, now)`, ids `{pendingId: p.id}`; `answer.choices` -> `t = await
      saveThread({id: "", discordUserId, question, decision, ephemeral: answer.ephemeral},
      now)`, ids `{threadId: t.id}` (saveThread mints the id: use the returned one);
   8. `payloads = renderAnswer(answer, ids)`.
8. Delivery: `api = discordApi()`, token `i.token`.
   - If `answer.ephemeral` and not `req.ephemeral` (the deferral was public): edit the
     original to "I sent you the answer privately." (with `allowed_mentions: {parse: []}`),
     then send every payload as a followup with `flags: 64`.
   - Otherwise edit the original with payload 0 and send the rest as followups.
9. Any error anywhere: log warn "ask.failed" `{requestId, error: name, status}`, then
   `editOriginal(token, renderError(userMessageFor(err), req.ephemeral))`. If that edit
   fails too, log error "ask.reply_failed"; never rethrow.
10. Log info "ask.done" `{requestId, route, ms}`.
