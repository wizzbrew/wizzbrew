Discord types are `import type` only; numeric literals at runtime: interaction types 1 PING, 2

BEHAVIOR: dispatch.ts (requestId = crypto.randomUUID(), now = new Date(); never throws)
1. type 1 -> `{type: 1}`.
2. type 2 command:
   - `isPaused()` true -> `{type: 4, data: {content: "Wizzbrew is paused right now.", flags: 64,
     allowed_mentions: {parse: []}}}` (applies to every command).
   - deferral visibility: link, unlink, me -> ephemeral (flags 64); everything else public.
   - Reply `{type: 5, data: {flags}}` and `waitUntil(work)` where work builds `asker =
     loadAsker(i)`, `target = {kind: "interaction", token: i.token, ephemeral}` and then:
     - ask: question = normalizeInput(option "question", i.data.resolved); `runAskPipeline({...,
       history: []})`;
     - schedule with no free text: `deliver(target, await scheduleAnswer({day: parseUserDate(day,
       now) if given, stage, tournament}, now), {})`;
     - live, standings, player, me: `runAskPipeline` with `forced` from `shortcutRequest` (me ->
       route my_stuff, live -> route live);
     - link, unlink: `runAskPipeline` with forced `{route: "account", confidence: 1, params:
       {accountAction}, reason: "shortcut /<name>"}`;
     - unknown command -> immediate `{type: 4, ...ephemeral "I don't know that command."}`.
     Any error inside work -> `deliverError(target, userMessageFor(err))`.
3. type 3 component, `a = decodeCustomId(custom_id)`; presser = `i.member?.user ?? i.user`:
   - null -> `{type: 4}` ephemeral "That button isn't mine."
   - followup: `loadThread(a.threadId, presser.id, now)`: "expired" -> type 4 ephemeral "That
     conversation expired. Ask again."; "not_yours" -> type 4 ephemeral "That conversation is
     private."; a thread -> respond with the modal (step 5).
   - change: `takePending(a.pendingId, presser.id, now)`: not_yours -> type 4 ephemeral "Only the
     person who asked can change this."; expired -> type 4 ephemeral "That request expired. Ask
     again."; taken (now cancelled) -> the modal for `a.threadId` titled "What should change?".
   - private: `{type: 5, data: {flags: 64}}` and `waitUntil(runComponent(i, requestId, now))`.
   - confirm, cancel, choose: `{type: 6}` and `waitUntil(runComponent(i, requestId, now))`.
4. type 5 modal submit: custom_id decodes to followup; question = the text input `question`;
   `loadThread` as in 3 (errors as type 4 ephemeral); reply `{type: 5, data: {flags:
   thread.ephemeral ? 64 : 0}}` and waitUntil `runAskPipeline({requestId, asker: await
   loadAsker(i), question: normalizeInput(question), reply: {kind: "interaction", token, ephemeral:
   thread.ephemeral}, history: thread.turns, threadId: thread.id, now})`.
5. The modal: `{type: 9, data: {custom_id: encodeCustomId({kind: "followup", threadId}), title:
   "Ask a follow-up" (or the change title), components: [{type: 1, components: [{type: 4,
   custom_id: "question", label: "Your follow-up", style: 2, max_length: 500, required: true}]}]}}`.
6. Other interaction types -> 400.

BEHAVIOR: shortcuts.ts
