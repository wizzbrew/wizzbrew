BEHAVIOR: link.ts (Discord user = `i.member?.user ?? i.user`; all edits carry
`allowed_mentions: {parse: []}`)
1. /link: existing `getLink(id)` -> edit "You're linked to Wizzrobe as <username>. Run /unlink
   first to switch accounts." Otherwise `{url} = await startLink(id)` and edit with content
   "Link your Wizzrobe account so I can act for you. The link works once and expires in 10
   minutes." and one action row with a link button (type 2, style 5, label "Link Wizzrobe",
   url).
2. /unlink: no link -> "You're not linked." Otherwise `revoke(await
   open(rec.sealedRefreshToken))`; a revoke failure is logged warn "link.revoke_failed" with
   the status only, and unlinking continues; `deleteLink(id)`; edit "Unlinked. Run /link any
   time to connect again."
3. /me: `runAskPipeline({requestId, interaction: i, question: "Show my upcoming matches,
   signups, volunteer shifts and requests.", ephemeral: true, forced: {route: "my_stuff",
   confidence: 1, params: {}, reason: "shortcut /me"}, now})`.
4. Errors in /link or /unlink: `editOriginal(token, renderError(userMessageFor(err), true))`;
   never rethrow.

BEHAVIOR: callback.ts
5. Read `code`, `state`, `error` from the query. `error` present -> 400 page "Linking was
   cancelled. You can close this tab." Missing code or state -> 400 "This link is incomplete.
   Run /link in Discord again."
6. `await finishLink(code, state)` -> 200 page "Linked. Go back to Discord; I can act for you
   now. You can close this tab." UserInputError -> 400 with its message. WizzrobeError -> 502
   "Wizzrobe didn't accept the link (<detail>). Run /link again." Anything else -> 500 "Something
   went wrong. Run /link again." and log error.
7. The page: a minimal HTML document (title "Wizzbrew", one paragraph, all text HTML-escaped),
   headers `Content-Type: text/html; charset=utf-8`, `Cache-Control: no-store`,
   `Referrer-Policy: no-referrer`. Never echo the code, state or a token.
