GOAL
Implement the Wizzrobe MCP layer: connector params for responder calls (Anthropic calls
Wizzrobe), and a direct `callTool` client for confirmed writes and code-side reads.

CONTEXT
Responders turn on only their route's read tools on the Messages API MCP connector. Confirmed
writes and a few code-side reads call Wizzrobe directly with the right person's token. Wizzrobe
reports tool failures as text starting with a code (`not_found: ...`), not as HTTP statuses.
Limit: 120 requests a minute per token.

BEHAVIOR
1. connectorParams(token, readTools) returns exactly:
   - `mcp_servers: [{ type: "url", url: config().wizzrobeMcpUrl, name: "wizzrobe",
     authorization_token: token }]`
   - `tools: [{ type: "mcp_toolset", mcp_server_name: "wizzrobe", default_config: { enabled:
     false }, configs: { <each read tool>: { enabled: true } } }]`
   - `betas: ["mcp-client-2025-11-20"]`
   An empty readTools list returns empty `mcp_servers` and `tools` arrays (a toolset with
   nothing enabled is pointless) and still the beta.
2. The real raw call: `new Client({ name: "wizzbrew", version: "0.1.0" })`, connect with
   `new StreamableHTTPClientTransport(new URL(config().wizzrobeMcpUrl), { requestInit: {
   headers: { Authorization: "Bearer " + token } } })`, `client.callTool({ name, arguments:
   args })`, then close (in `finally`). Result text = the `text` of the `type: "text"` content
   entries joined; `isError` from the result. A transport error that carries an HTTP status
   (StreamableHTTPError's `code`, or a 401 from the server) -> `WizzrobeError(status, message,
   Retry-After if present)`; any other transport failure -> `WizzrobeError(503, "could not reach
   Wizzrobe")`. Follow the installed SDK's real names; note differences under DEVIATIONS.
3. callTool(token, name, args):
   - `args = { ...args, tenant: config().wizzrobeTenant }` for every tool except `whoami` and
     `list_tenants` (the tenant always comes from config, never from the caller);
   - read cache: if `name` is in READ_TTL (`list_stages` 120, `get_stage` 120,
     `list_tournaments` 120, `get_tournament` 120, `list_randomizers` 120, `get_schedule` 30,
     `list_matches` 30, `get_match` 30), look up `keys.cache("mcp", sha256hex(token + "\n" +
     name + "\n" + stableJson(args)))`; a hit returns the cached value. Never cache any other
     tool (writes, whoami, anything user-specific);
   - call the raw function. `isError` -> map the text: `^(\w+):\s*(.*)` gives code and
     message; not_found 404, forbidden 403, unauthorized 401, invalid_request 400, any code
     starting with `rate` 429, anything else (or no code) 500; throw `WizzrobeError(status,
     message || text)`;
   - success: `JSON.parse(text)` and return as is (list tools come as `{"result": [...]}`);
     unparseable text -> `WizzrobeError(502, "Wizzrobe sent a reply that isn't JSON")`; cache
     reads with their TTL;
   - a 429 (tool text or transport) retries once after `min(retryAfterSec ?? 1, 10)` seconds;
     a second 429 propagates.
   - Log info "wizzrobe.tool" `{name, ok, ms, cached}`: never args values or tokens.
4. `setRawToolCallForTests(f)` swaps the raw function; null restores the real one.
