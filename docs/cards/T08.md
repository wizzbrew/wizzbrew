Fixture files carry a `_note` key; the fakes strip it before answering.

BEHAVIOR
1. FakeKv: in-memory map of `{value, expiresAt | null}`; values are deep-copied with
   structuredClone on set and get (Upstash round-trips JSON). `get` of an expired key returns
   null and deletes it. `incrByFloat` treats missing as 0; with ttlSec it sets the TTL. `expire`
   on a missing key does nothing. Default clock `Date.now`.
2. FakeAnthropic: `beta.messages.create(params)` pushes `structuredClone(params)` to
   `requests`, shifts the queue, resolves the message; empty queue -> throws
   `Error("FakeAnthropic: no scripted response")`.
3. fakeMessage: a complete BetaMessage per the installed type: `id` "msg_fake_<n>" (counter),
   `type` "message", `role` "assistant", `model` opts.model ?? "claude-sonnet-5-5", the content,
   `stop_reason` opts.stop_reason ?? ("tool_use" if any block is `tool_use`, else "end_turn"),
   `stop_sequence` null, usage defaults `{input_tokens: 100, output_tokens: 50,
   cache_creation_input_tokens: 0, cache_read_input_tokens: 0}` merged with opts.usage, and
   every other required field set to null or its empty value per the .d.ts.
4. block helpers, shapes per the installed types:
   - text: `{type: "text", text, citations: null}`
   - thinking: `{type: "thinking", thinking, signature: "sig_fake"}`
   - toolUse: `{type: "tool_use", id: id ?? "toolu_fake_<n>", name, input}`
   - mcpToolUse: `{type: "mcp_tool_use", id: id ?? "mcptoolu_fake_<n>", name, server_name:
     "wizzrobe", input}`
   - mcpToolResult: `{type: "mcp_tool_result", tool_use_id, is_error: isError ?? false,
     content: [{type: "text", text, citations: null}]}`
   If the installed type requires extra fields or names them differently, follow the type and
   note it under DEVIATIONS. Cast through `as BetaContentBlock` only when the union demands it.
5. FakeDiscordApi: records each call (`token` null for registerCommands, `body` = commands
   array there); `failNext(err)` makes exactly the next call reject with err (still recorded).
6. FakeWizzrobe.rawToolCall(token, name, args): record `{tool: name, token, args}`, then answer
   in this order:
   - failTool set for name -> `{isError: true, text: "<code>: <message>"}`;
   - featuresOff (default true) and name matches /bracket|qualifier|race_room/ ->
     `{isError: true, text: "not_found: This feature is not enabled for this community."}`;
   - answer() override -> `{isError: false, text: JSON.stringify(result)}`;
   - fixture `tests/fixtures/wizzrobe/<name>.json` (resolve with
     `new URL("../fixtures/wizzrobe/", import.meta.url)`, read with fs) without `_note`;
   - a write tool (signup_as_crew, withdraw_crew_signup, acknowledge_match,
     offer_match_for_stream, withdraw_stream_offer, watch_match, unwatch_match,
     sign_up_for_tournament, withdraw_from_tournament, submit_match_request,
     suggest_match_time) -> `{isError: false, text: '{"ok":true}'}`;
   - otherwise `{isError: true, text: "not_found: no fixture for <name>"}`.
7. FakeWizzrobe.fetch(input, init): match on method and path (ignore origin), Bearer token from
   the Authorization header; record `{tool: "rest:<METHOD> <path>", token, args: parsed JSON
   body or {}}`. failRest(path, ...) matches when the request path starts with `path`: answer
   that status, JSON `{detail}`, and a `Retry-After` header when given. Otherwise:
   - POST /api/matches/{id}/reschedule-requests -> 201 rest_create_reschedule_request.json
   - POST /api/brackets/matches/{id}/games -> 201 rest_book_bracket_game.json
   - GET /api/brackets/my-open-matches -> 200 the bare array from
     rest_my_open_bracket_matches.json `result`
   - anything else -> 404 `{"detail": "Not Found"}`. Responses are real `Response` objects
     with `Content-Type: application/json`.
8. FakeChallonge.fetch: records the full URL; after fail(status) answers that status with
   `{"errors": [{"status": "<status>", "detail": "fake failure"}]}`. Otherwise, by path under
   `https://api.challonge.com/v2.1/tournaments/<id>`: `.json` -> tournament.json,
   `/participants.json` -> participants.json, `/matches.json` -> matches.json; a `page`
   query above 1 -> `{"data": []}`; anything else 404.
9. combineFetch: the first route whose prefix the URL starts with handles it; none -> reject
   with `Error("no fake for <url>")`.
