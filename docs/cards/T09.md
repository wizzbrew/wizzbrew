BEHAVIOR
1. The real client: `new Anthropic({ apiKey: config().anthropicApiKey })` from
   "@anthropic-ai/sdk", created on first use, cached. `setAnthropicForTests(c)` swaps it; null
   resets so the next call builds a real one. Call `client.beta.messages.create(...)`.
2. createMessage, in order:
   1. `await assertUnderBudget(ctx.now)` (BudgetExceededError propagates; no API call).
   2. `model = MODELS[purpose]`; `max_tokens = Math.max(params.max_tokens ?? 4000, 4000)`
      (L9: never under 4000).
   3. `msg = await client.beta.messages.create({ ...params, model, max_tokens })`. SDK errors
      propagate unchanged (L16); log them at warn with `{requestId, purpose, status}` first.
   4. `usd = await recordSpend(msg.model, msg.usage, ctx.now)` (price by the model that
      answered, L12).
   5. Log one info line, event "anthropic.call": `{requestId, purpose, model: msg.model,
      stop_reason, input_tokens, output_tokens, cache_read_input_tokens,
      cache_creation_input_tokens, usd}`. Never log message text or the prompt (L24).
   6. `stop_reason === "refusal"` -> throw `new ModelOutputError("refusal", "the model
      declined this request")`; `"max_tokens"` -> `new ModelOutputError("max_tokens", "the
      answer ran past max_tokens")`. Spend is recorded before either throw. Every other stop
      reason (end_turn, tool_use, pause_turn, stop_sequence) returns `msg`.
   7. Callers own `system` (including any `cache_control` on the stable block) and
      `output_config`; pass them through untouched.
3. textOf: the `text` of every block with `type === "text"`, in order, joined with "", then
   trimmed. Never index `content[0]`. No text blocks -> "".

TESTS (tests/unit/client.test.ts)
- Use `FakeAnthropic` with `setAnthropicForTests`, and `FakeKv` (tests/fakes/kv.ts) with
  `setKvForTests` from src/store/kv.js, so budget and spend run for real.
- A response whose first block is thinking, then text: textOf returns the text (L9).
- Two text blocks around a tool_use: joined in order; no text -> "".
- `max_tokens: 1000` is sent as 4000; `max_tokens: 8000` stays 8000; `model` comes from
  MODELS for each purpose.
- `betas`, `system` and `output_config` reach the fake unchanged.

  fake's usage and model.

  received no request.
- The log line (spy on `console.log` or `process.stdout.write`, whichever log.ts uses) has the
  requestId and no question text.
