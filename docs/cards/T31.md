GOAL
Implement the one pipeline every question takes (slash, follow-up, button choice, @mention,
reply) and the delivery step that sends an answer to an interaction or as a message reply,
keeping personal answers private.

CONTEXT
Wizzbrew is a conversational Discord bot (plan.md "Interaction model"). Every capability is one
handler: the pipeline routes (unless forced) and then calls the account handler, the direct live
answer, or a responder. Every failure ends in an honest reply (L16, L17). Permission checks are
code, after routing.

export interface PipelineRequest { requestId: string; asker: Asker; question: string; reply: ReplyTarget; history: ConversationTurn[]; threadId?: string; forced?: RoutingDecision; now: Date }
export function runAskPipeline(req: PipelineRequest): Promise<void>;   // never throws

BEHAVIOR: runAskPipeline (one try/finally; the lock is always released)
1. Lock: `kv().setIfAbsent(keys.lock(asker.discordUserId), requestId, 120)` false ->
   `deliverError(reply, "Still working on your last one. Ask again in a moment.")` and stop
   (don't release someone else's lock). Release with `kv().del` in finally.
2. `isPaused()` -> deliverError "Wizzbrew is paused right now." and stop.
3. Unless `forced?.route === "live"`: `assertUnderBudget(now)`.
4. `decision = forced ?? await routeQuestion({requestId, asker, question, now, ephemeral:
   reply.kind === "interaction" && reply.ephemeral, history})`.
5. Auth gate: route auth linked without `asker.linked` -> `NotLinkedError("")`; staff without
   role "staff" or "admin" -> `UserInputError("That's for event staff.")`.
6. Answer: route account -> `accountAnswer(decision.params.accountAction ?? "link", asker, now)`;
   live -> `liveAnswer(now)`; else `runResponder(route, decision, ctx)` with ctx history.
7. pendingId: `createPending` when `answer.proposedAction`.
8. Thread: always save a new one, `saveThread({id: "", discordUserId, question, decision,
   ephemeral: answer.ephemeral, turns: [...history, {role: "user", text: question}, {role:
   "assistant", text: answer.text}], held}, now)`, where held = `{answer, pendingId}` only when
   `reply.kind === "message"` and `answer.ephemeral`. Use the returned id.
9. `deliver(reply, answer, {pendingId, threadId})`.
10. Errors: log warn "ask.failed" `{requestId, name, status}`; for errors that are not the user's
    (anything except UserInputError, NotLinkedError, BudgetExceededError and WizzrobeError
    400/401/403/404), `alertStaff("ask." + name, clip(message, 300))`; then
    `deliverError(reply, userMessageFor(err))`.
11. Log info "ask.done" `{requestId, route, ms, path: reply.kind}`.

BEHAVIOR: deliver.ts
12. interaction target: `payloads = renderAnswer(answer, ids)`.
    - `answer.ephemeral && !target.ephemeral`: editOriginal "I sent you the answer privately."
      (allowed_mentions empty, components []) then every payload as a followup with `flags: 64`.
    - otherwise editOriginal with payload 0, the rest as followups (flags 64 when
      target.ephemeral).
13. message target:
    - `answer.ephemeral`: `postMessage(channelId, renderPrivateStub(ids.threadId), messageId)`
      (threadId required here; missing -> Error).
    - otherwise payload 0 via `postMessage(channelId, p0, messageId)` and the rest via
      `postMessage(channelId, p)` without a reply reference.
14. deliverError: interaction -> `editOriginal(token, renderError(message, target.ephemeral))`;
    message -> `postMessage(channelId, {content: message, allowed_mentions: {parse: []}},
    messageId)`. A failure here logs error "deliver.failed" and never throws.
