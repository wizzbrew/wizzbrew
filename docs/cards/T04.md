CONTRACT (do not change)
```ts
// discord/render.ts
export function renderAnswer(a: Answer, ids?: { pendingId?: string; threadId?: string }): RESTPatchAPIInteractionOriginalResponseJSONBody[];
// pendingId -> Confirm/Cancel buttons; threadId -> one "choose" button per choice
export function renderError(message: string, ephemeral: boolean): RESTPatchAPIInteractionOriginalResponseJSONBody;
// every payload carries allowed_mentions: { parse: [] } (L20)

// discord/components.ts
export type ComponentAction =
  | { kind: "confirm"; pendingId: string }
  | { kind: "cancel"; pendingId: string }
  | { kind: "choose"; threadId: string; value: string };
export function encodeCustomId(a: ComponentAction): string;   // <= 100 chars
export function decodeCustomId(id: string): ComponentAction | null;
```
`Answer` is in src/types.ts. Discord types are `import type` from "discord-api-types/v10"; use
numeric literals at runtime (action row 1, button 2; button styles: 2 secondary, 3 success,
4 danger).

BEHAVIOR
1. custom_id format: `wb:confirm:<pendingId>`, `wb:cancel:<pendingId>`,
   `wb:choose:<threadId>:<value>`. Ids match `^[A-Za-z0-9_-]{1,40}$`. `value` is everything
   after the third colon (it may contain colons), non-empty.
   - encodeCustomId throws a plain Error for a bad id, empty value, or a result over 100 chars.
   - decodeCustomId returns null for any malformed input (wrong prefix, unknown kind, bad id,
     missing value, over 100 chars); never throws.
2. renderAnswer(a, ids):
   - `chunks = finalizeText(a.text)` (import from "./markup.js").
   - One payload per chunk. Payload 0: `{content, embeds: a.embeds ?? [], components,
     allowed_mentions: {parse: []}}`. Later payloads: `{content, allowed_mentions: {parse: []}}`
     plus `flags: 64` when `a.ephemeral` (they go out as followups; payload 0 edits the deferred
     reply, whose visibility was set at deferral, so it carries no flags).
   - components on payload 0: if `ids.pendingId`, one action row with Confirm (style 3, label
     "Confirm") and Cancel (style 4, label "Cancel"). If `ids.threadId` and `a.choices`, one
     action row with up to 5 secondary buttons (style 2), label = choice label cut to 80 chars,
     custom_id from `{kind: "choose", threadId, value}`; skip a choice whose custom_id would
     exceed 100 chars. No ids -> `components: []`.
3. renderError(message, ephemeral): `{content: finalizeText(message)[0], embeds: [],
   components: [], allowed_mentions: {parse: []}}`. (`ephemeral` is accepted for symmetry; the
   deferral already set visibility.)
