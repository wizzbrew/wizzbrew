BEHAVIOR: resolveByName
1. norm(s): Unicode NFD, drop combining marks, lowercase, collapse whitespace, trim.
   alias(s): norm(s), drop a leading "the ", replace every character that isn't a letter, digit
   or space with a space, collapse spaces, trim.
2. Empty input after norm -> none. Then, stopping at the first step with any hit:
   1. names whose norm equals norm(input): one -> match; several -> ambiguous (all of them);
   2. names whose alias equals alias(input): same rule;
   3. whole-word prefix: names whose alias starts with alias(input) followed by a space or the
      end: one -> match; several -> ambiguous (all, in input order);
   4. otherwise none.
   No fuzzy scoring, no shortest-wins.
