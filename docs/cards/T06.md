BetaUsage (from "@anthropic-ai/sdk/resources/beta/messages/messages") has `input_tokens`,

number | null`. `input_tokens` already excludes cached tokens.

BEHAVIOR
1. PRICING, USD per million tokens (Anthropic first-party rates, checked 2026-10-15; cache
   write is the 5-minute TTL, 1.25x input; Haiku's rates apply to prompts up to 100K tokens,
   which is every Wizzbrew prompt):
   - claude-haiku-5-5: in 0.10, out 0.50, cacheRead 0.01, cacheWrite 0.125
   - claude-sonnet-5-5: in 2.00, out 10.00, cacheRead 0.20, cacheWrite 2.50
2. At module load, every MODELS value must have a PRICING entry, else throw
   `Error("no pricing for <id>")` (L12: an unknown model fails at startup).
3. recordSpend: unknown model -> throw the same Error. usd = (input * in + output * out +
   cacheRead * cacheReadPerM + cacheWrite * cacheWritePerM) / 1e6, with null counts as 0.
   `await kv().incrByFloat(keys.spend(communityDate(now)), usd, 172800)` (48 h TTL). Return usd.
4. assertUnderBudget: spent = `Number(await kv().get(keys.spend(communityDate(now))) ?? 0)`;
   if spent >= `config().anthropicDailyBudgetUsd`, throw
   `BudgetExceededError("daily Anthropic budget reached")`.
5. Imports: kv from "../store/kv.js", keys from "../store/keys.js", communityDate from
   "../time/time.js", config from "../config.js", BudgetExceededError from "../errors.js".
